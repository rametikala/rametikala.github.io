# Blog posts

Add one Markdown file per post in this folder, named `YYYY-MM-DD-short-name.md`, for example `2026-11-21-why-rtk-matters.md`. The date in the file name becomes the post date. This README is ignored by the website.

Optional header block at the top of a post:

```
<!--portfolio
title: Your post title
dek: One sentence that makes someone want to read it.
topics: Mapping, Product decisions
image: cover.png
-->
```

Without it, the title comes from the first `# heading` and the summary from the first paragraph.
